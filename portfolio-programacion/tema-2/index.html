Tema 2: Estructuras de control

Condiciones, bucles y sentencias de salto.

Ejemplos trabajados en clase

  1. Condiciones if y else — Compruebo los lados de un triángulo y lo clasifico.
  2. Selección con switch — Introduzco una nota y muestro la calificación correspondiente.
  3. Bucle for y continue — Muestro los números pares saltando los impares.
  4. Bucle while — Calculo el factorial repitiendo una multiplicación.
  5. Bucle do-while — Sumo números hasta introducir cero.
  6. Uso de break — Termino un bucle cuando se cumple una condición.
  7. Uso de continue — Salto una vuelta del bucle cuando se cumple una condición.

Programa completo: control de notas

En este ejercicio junto varias estructuras: un while para repetir, if / else para comprobar las notas, switch para mostrar la calificación, continue para saltar una nota incorrecta y break para terminar.

Prueba y depuración

Para revisar el programa, puedo poner un punto de interrupción justo después de leer la nota y avanzar paso a paso comprobando las variables nota, suma y cantidad.

Momento nota suma cantidad
Después de introducir 8 8 0 0
Después de procesar el 8 8 8 1
Al introducir 11 (no válida) 11 8 1
Después de procesar el 5 5 13 2

En NetBeans, el punto de interrupción se coloca en la línea que lee la nota. Al ejecutar en modo depuración se pueden observar esos valores en cada paso.
